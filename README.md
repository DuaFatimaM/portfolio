# My Personal Portfolio

A simple and clean personal portfolio website built with HTML and CSS, showcasing skills, projects, hobbies, and contact information.

## Project Structure

```
portfolio/
├── index.html          # Home page
├── skills.html         # Skills page
├── gallery.html        # Image gallery
├── hobbies.html        # Hobbies page
├── contact.html        # Contact information
├── css/
│   └── style.css       # External stylesheet
├── images/
│   ├── photo1.jpg
│   ├── photo2.jpg
│   ├── photo3.jpg
│   ├── photo4.jpg
│   └── photo5.jpg
└── README.md           # Project documentation
```

## Features

- **Responsive Navigation Menu**: Horizontal navigation bar with links to all pages
- **Float and Clear Layout**: Gallery and content arranged using CSS float property
- **External CSS Stylesheet**: All styling in a separate `style.css` file
- **Image Gallery**: Displays at least 5 images with float-based layout
- **Mobile Responsive**: Adapts to different screen sizes
- **Clean Design**: Simple, professional styling with consistent colors and fonts

## Pages

1. **Home** (`index.html`) - Welcome page with profile image and about section
2. **Skills** (`skills.html`) - Display of technical skills
3. **Gallery** (`gallery.html`) - Image gallery with float alignment
4. **Hobbies** (`hobbies.html`) - Personal hobbies and interests
5. **Contact** (`contact.html`) - Contact information and social links

## Getting Started

### Local Setup

1. Clone or download this repository
2. Place your images in the `images/` folder
3. Open `index.html` in your web browser

### Deploy on GitHub Pages

1. Create a GitHub repository named `portfolio`
2. Push all files to the repository
3. Go to repository settings → GitHub Pages
4. Select `main` branch as the source
5. Your portfolio will be live at: `https://username.github.io/portfolio/`

## CSS Features Used

- **Float**: Used for image positioning and gallery layout
- **Clear**: Used to prevent layout issues with floated elements
- **Flexbox**: Used for navigation menu alignment
- **Grid**: Used for skills, hobbies, and contact sections
- **Responsive Media Queries**: Mobile-friendly design

## Technologies

- HTML5
- CSS3 (Float, Clear, Flexbox, Grid)
- No JavaScript or frameworks
